Autonomous Grid Contingency Remediation

Complete Architecture, Data Flow, Neural Layers & Contingency Ranking Guide

Part 1 End-to-End Pipeline: From Data to Action

The system operates in a closed autonomous loop. It senses a power grid outage, classifies whether the system is in danger, and uses an intelligent Reinforcement Learning Agent to automatically re-balance the grid without human intervention.

1

Base Network Ingestion

Loads the standard IEEE 14-bus transmission system (14 electrical substations, 20 high-voltage transmission lines and transformers, 5 power generators). Nominal system power is 100 Megawatts (base MVA) and 144 Kilovolts.

2

Scenario & Load Generation

In the real world, electricity usage fluctuates constantly. The pipeline creates thousands of non-repeating scenarios by randomly scaling loads across 11 load substations between 80% and 120% of their normal demand.

3

N-1 Contingency Injection

For every load scenario, the system simulates an "N-1 contingency" (a sudden trip or failure of 1 branch at a time across all 20 lines, simulating storm damage, lightning strikes, or line faults).

4

AC Newton-Raphson Physics Solver

Solves non-linear AC power flow equations (Kirchhoff's Current Law and complex power balance). If the power flow converges, it calculates the exact voltage magnitude at all 14 buses, phase angles, and electrical power flow on every transmission line. If the grid is so badly broken that power cannot physically flow, the solver flags "Non-convergence".

5

Feature Extraction & Dual Security Classification

Results are packaged into a structured 63-column feature row. The state is then evaluated two ways:
• Physics Ground Truth: Compares numbers to industry grid limits (Voltages between 0.95 and 1.10 per-unit, Line loading under 100%).
• Deep Neural Classifier: Uses a 3-layer neural network (79 inputs) to predict if the state is Safe, Alert, or Critical in under 1 millisecond.

6

DQN Corrective Action Dispatch

If the grid is Alert or Critical, the 77-dimensional grid state is fed into the Deep Q-Network Agent. The agent chooses the best physical corrective action (adjusting generator outputs or cutting 10% load at a stressed bus).

7

Post-Remediation Verification

The action is physically applied to the grid, the AC power flow is re-solved, and the new state is measured. The agent receives a reward or penalty based on whether the grid returned to a Safe operating state.

1. What are the 77 Input Numbers?

The input vector is a continuous 77-dimensional numerical snapshot of the electrical state:

  • Indices 0 to 13 (14 numbers): Bus voltage magnitudes at all 14 substations (nominal is 1.00 per-unit).
  • Indices 14 to 27 (14 numbers): Bus voltage phase angles in degrees, divided by 30 to keep them in a clean -1 to +1 range.
  • Indices 28 to 47 (20 numbers): Transmission line loadings in percentage (e.g. 85% = 0.85). If a line is at 150%, it reads 1.50.
  • Indices 48 to 52 (5 numbers): Generator active power outputs in Megawatts divided by 100.
  • Indices 53 to 72 (20 numbers): A one-hot outage mask. A list of 20 zeros, with a 1.0 placed exactly at the index of the line that failed.
  • Indices 73 to 76 (4 numbers): Global summary metrics: Minimum voltage, Maximum voltage, Peak line loading, and Total system load.

2. What is Layer 1 (77 → 256)?

This is a Fully Connected (Linear) layer containing 256 artificial neurons.

Each single neuron has 77 adjustable dials (weights) plus 1 bias number. That means this layer has (77 × 256) + 256 = 19,968 trainable parameters.

What do these 256 neurons learn to do?

  • Neuron #1 might activate strongly when "Line 1-2 tripped while Bus 4 voltage is under 0.92".
  • Neuron #42 might activate when "Generator at Bus 2 is maxed out and line 5-6 is over 115% loading".
  • Neuron #180 might detect "Everything is normal and voltages are balanced".

LayerNorm & ReLU:
• Layer Normalization stabilizes the 256 outputs so they don't explode to huge numbers or shrink to zero.
• ReLU (Rectified Linear Unit) introduces non-linearity. It says: if the neuron signal is negative, turn it off (0). If positive, let it pass. Without ReLU, a neural network is just a basic linear regression that could never learn complex power grid interactions!

3. What is Layer 2 (256 → 256)?

This is a second layer of 256 neurons connecting to the first layer. It contains (256 × 256) + 256 = 65,792 trainable parameters.

Instead of looking at raw voltages and line currents, Layer 2 combines the high-level concepts from Layer 1. For example, it combines "severe overload on branch 2-4" with "generator 3 has surplus capacity available". It synthesizes the full picture of grid distress.

4. What is the Output Layer (256 → 20)?

This final linear layer compresses the 256 internal features down into exactly 20 numbers.

Each output number corresponds to one specific physical action available to the agent:

Action Index Type Description & Physical Effect Cost
Action 0 Do Nothing Grid is safe or no intervention is needed. Leaves settings unchanged. 0.0
Actions 1 to 8 Redispatch Adjust power output by +10 MW or -10 MW on 4 controllable generators (Buses 2, 3, 6, 8). Re-routes power without cutting electricity to customers. Flat 2.0
Actions 9 to 19 Load Shedding Emergency measure: cut 10% of electrical demand at one of the 11 load buses (Buses 2, 3, 4, 5, 6, 9, 10, 11, 12, 13, 14) to prevent blackout. 1.0 per MW

What does the number output by the network mean?

These 20 numbers are Q-values (Quality values). A Q-value is the expected total cumulative reward the agent will achieve if it executes that action. If Action 3 has a Q-value of +48.2 and Action 0 has a Q-value of -15.0, the agent knows that Action 3 will save the grid, while doing nothing will result in voltage collapse and penalties!

Part 3 Execution Flow: Training Time vs. Testing Time

A major point of confusion in Reinforcement Learning is what happens while the agent is learning (Training) versus when it is evaluated in a real-world test (Testing/Inference). Here is the exact side-by-side comparison:

Training Time Flow (80,000 Episodes)

  1. Epsilon-Greedy Exploration:
    The agent starts completely clueless. With probability Epsilon (starts at 100%), it picks a completely random action to explore what happens. As training continues, Epsilon gradually decays down to 5%.
  2. Simulate & Reward:
    The action is sent to the power flow solver. The reward function calculates a score:
    • +50 if the grid becomes Safe.
    • -100 if the grid collapses.
    • Penalties for high voltage deviations and line overloads.
  3. Experience Replay Buffer:
    The transition tuple: (State, Action, Reward, Next State, Done) is stored into a 100,000-memory bank.
  4. Mini-Batch Gradient Descent (GPU):
    Every step, the agent grabs a random batch of 128 past memories from the buffer and sends them to the GPU.
  5. Bellman Error & Backpropagation:
    It calculates the target value using a separate Target Network:
    Target = Reward + 0.95 × max(Next State Q-values)
    The loss (difference between current guess and target) is computed, and the Adam optimizer updates all neural network weights.
  6. Target Synchronization:
    Every 200 steps, the Target Network copies the Policy Network weights to keep learning stable.

Testing / Inference Flow (20,000 Test Cases)

  1. Zero Exploration (Epsilon = 0):
    Exploration is completely turned off. The agent is in pure deployment mode. No random guesses are ever taken.
  2. Replay Buffer & Target Network Disabled:
    No memories are stored, no gradients are calculated, and no weights change. The network is frozen in evaluation mode.
  3. Fast Forward Pass:
    The 77-dimensional state is passed through the Policy Network. The network outputs the 20 Q-values in under 1 millisecond.
  4. Greedy Action Selection:
    The agent picks the action with the single highest Q-value:
    Selected Action = argmax(Q-values)
  5. Action Execution & Benchmark:
    The chosen action is applied to the power system. We measure:
    • Did the action convert a Critical grid to Safe?
    • Did it preserve already safe states?
    • How does it compare to the theoretical Oracle (Offline Best Exhaustive Search)?

Part 4 Contingency Ranking: What is it, and How Will We Use It?

The Real-World Problem: Emergency Room Triage

Imagine an emergency hospital room during a disaster. If 20 patients arrive at once, a doctor cannot spend 2 hours performing full surgery on patient #1 if patient #1 only has a minor scratch, while patient #5 is suffering severe cardiac arrest.

The hospital does triage: nurses quickly assign a severity score (critical, urgent, minor) and rank patients so the most life-threatening cases are treated first.

Contingency Ranking is the exact same triage system for the electrical power grid:

  • In an interconnected grid with hundreds of lines, most outages are benign (voltage drops by only 0.01 per-unit, lines stay at 50% capacity).
  • A small number of outages are catastrophic (lines carrying heavy corridor power suddenly trip, cascading overload to neighboring lines at 220% capacity or plunging voltage to 0.75 per-unit).
  • Contingency Ranking computes an analytical Severity Index for every possible outage and ranks them from Rank 1 (Most Dangerous) down to Rank 20 (Safest).

The Two Classic Severity Indices

Power engineers use two mathematical indices to score outages:

1. Voltage Severity Index (PI_V)

Measures how far bus voltages deviate from the safe boundary (0.95 to 1.10 per-unit). If a bus voltage stays at 1.02, deviation is 0. If it falls to 0.80 (very dangerous), the squared penalty is huge.

Plain Formula: For every substation, if voltage is outside the safe band, add (deviation / allowed_range)^2 to the score.

2. Thermal Overload Severity Index (PI_MW)

Measures how severely transmission lines are overloaded beyond their 100% capacity rating.

Plain Formula: For every branch, take (actual line loading / maximum rated loading)^4. Notice the power of 4:
• If a line is at 80% (0.8): 0.8^4 = 0.40 (low score).
• If a line is at 140% (1.4): 1.4^4 = 3.84 (high score).
• If a line is at 240% (2.4): 2.4^4 = 33.17 (exponentially massive score!).

3. Composite Severity Index (CSI)

Composite Severity = (Voltage Score) + (Thermal Score) + (Non-convergence Penalty)

If an outage causes power flow divergence (numerical collapse), it automatically receives a massive penalty of 10,000, immediately shooting to Rank 1 (Most Critical).

How We Will Use It in Our Project (Action Plan)

Here is how this adds value to your project and thesis:

  1. Intelligent Agent Prioritization: When multiple contingencies occur or during real-time surveillance, the control system computes the ranking and feeds the Rank 1, 2, and 3 contingencies to the DQN agent first.
  2. Fast Screening Filter: Instead of running heavy simulations on all 20 lines, the system can instantly discard safe lines (Rank 10 to 20) and only run the Neural Classifier and RL Agent on top-ranked lines.
  3. Curriculum Learning: During training, we can train the RL agent on the toughest contingencies first, accelerating learning efficiency.
